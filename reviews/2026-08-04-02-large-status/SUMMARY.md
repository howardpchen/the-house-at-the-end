# Summary

Version 0.1.6 enlarges the house status from Gothic 18 to Gothic 24. A two-row,
three-column grid preserves the existing action and footer space. Emery uses
full `Fire` and `Guest` labels; Basalt uses compact `F` and `G` labels. Both
show kindling, remnants, rations, and clarity as `K`, `M`, `R`, and `C`.

Normal and near-maximum three-digit values fit on both target displays without
overlap. Host tests and the universal Basalt/Emery build passed. Emulator
installs passed on both targets. The Time 2 CloudPebble install reported
`App install succeeded`; physical readability remains for the wearer to
validate.
